# Explore With Me

## Описание проекта

**Explore With Me** (англ. «исследуй со мной») — приложение которое позволит пользователям делиться информацией об интересных событиях и находить компанию для участия в них.

Проект состоит из двух основных модулей:
- **Основной сервис (main-service)** - управление событиями, пользователями, категориями и запросами на участие
- **Сервис статистики (stats-service)** - сбор и анализ статистики просмотров событий

## Основные Endpoint'ы

### Публичное API (Public)

#### События (Events)
- `GET /events` - Получение событий с фильтрацией
- `GET /events/{id}` - Получение подробной информации о событии

#### Категории (Categories)
- `GET /categories` - Получение категорий событий
- `GET /categories/{id}` - Получение категории по ID

#### Компиляции (Compilations)
- `GET /compilations` - Получение подборок событий
- `GET /compilations/{id}` - Получение подборки по ID

#### Комментарии (Comments)
- `GET /events/{eventId}/comments` - Получение опубликованных комментариев к событию

### Приватное API (Private)

#### События пользователя
- `GET /users/{userId}/events` - Получение событий пользователя
- `POST /users/{userId}/events` - Создание нового события
- `GET /users/{userId}/events/{eventId}` - Получение события пользователя
- `PATCH /users/{userId}/events/{eventId}` - Обновление события

#### Запросы на участие
- `GET /users/{userId}/requests` - Получение запросов пользователя
- `POST /users/{userId}/requests` - Создание запроса на участие
- `PATCH /users/{userId}/requests/{requestId}/cancel` - Отмена запроса

#### Комментарии пользователя
- `POST /users/{userId}/events/{eventId}/comments` - Создание комментария
- `GET /users/{userId}/comments` - Получение комментариев пользователя
- `GET /users/{userId}/comments/{commentId}` - Получение конкретного комментария
- `PATCH /users/{userId}/comments/{commentId}` - Обновление комментария
- `DELETE /users/{userId}/comments/{commentId}` - Удаление комментария

### Административное API (Admin)

#### Пользователи
- `POST /admin/users` - Создание пользователя
- `GET /admin/users` - Получение пользователей
- `DELETE /admin/users/{userId}` - Удаление пользователя

#### Категории
- `POST /admin/categories` - Создание категории
- `DELETE /admin/categories/{catId}` - Удаление категории
- `PATCH /admin/categories/{catId}` - Обновление категории

#### События
- `GET /admin/events` - Поиск событий
- `PATCH /admin/events/{eventId}` - Редактирование события

#### Компиляции
- `POST /admin/compilations` - Создание подборки
- `DELETE /admin/compilations/{compId}` - Удаление подборки
- `PATCH /admin/compilations/{compId}` - Обновление подборки

#### Комментарии
- `GET /admin/comments` - Получение комментариев с фильтрацией
- `PATCH /admin/comments/{commentId}` - Модерация комментария
- `DELETE /admin/comments/{commentId}` - Удаление комментария

## Дополнительная функциональность: Система комментариев

- **Pull Request с реализацией комментариев**: https://github.com/Landenv/java-explore-with-me/pull/3

### Описание
Реализована полноценная система комментариев к событиям с трехуровневой системой модерации, позволяющая пользователям оставлять отзывы о мероприятиях, а администраторам — модерировать контент.

### Основные возможности:

#### Для пользователей:
- **Создание комментариев** к опубликованным событиям
- **Просмотр своих комментариев** 
- **Редактирование комментариев** в статусе "на модерации"
- **Удаление своих комментариев**

#### Для администраторов:
- **Модерация комментариев** - изменение статусов (PENDING → APPROVED/REJECTED)
- **Фильтрация комментариев** по событиям и статусам
- **Удаление любых комментариев**

#### Для всех пользователей:
- **Просмотр одобренных комментариев** к событиям

### Статусы комментариев:
- **PENDING** - на модерации (можно редактировать)
- **APPROVED** - одобрен (виден всем)
- **REJECTED** - отклонен (не виден публично)
